HAYABUSA · DFIR CONSOLE

隔離した解析環境で、
証跡を検証しながら調査する。

EVTX は収集用の端末から解析ホストへ取り込み、SHA-256 を記録してから検査します。検知は日本語で解説され、ケース単位で証跡・判定・監査履歴を追跡できます。

実行環境— 待受— 証跡SHA-256 記録 認証—
  1. 01証跡を取り込むEVTX / ZIP ・ハッシュ記録
  2. 02ケースで解析するSigma + IoC ・案件単位
  3. 03証跡を確認するハッシュ / 監査 / レポート
解析対象の端末上では実行しないでください。ログは収集ツールで取得し、この解析ホストへ持ち込んでください。 GitHub
